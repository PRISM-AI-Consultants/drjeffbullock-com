The PRISM Studios Model Leaderboard answers one question: which AI model should you use right now? It ranks video, image, voice, music and language models for best overall, best value and best for each job.

## How it works

- **Our own tests count most.** Where PRISM Studios has run a head-to-head test or used a model in real work, that evidence leads.
- **Public arena ranks** are read from the public leaderboards and shown with where and when they were read.
- **Live provider prices** link to the provider's own pricing page, with the date they were checked.

Every score and every price links back to its source, so you can check it yourself.
